## 📊 TEMPLATE FOCUS GROUP DISCUSSION GUIDE

### Pre-Session Preparation

**Participant Selection Criteria:**
```
- Mixed demographic representation
- Various technology comfort levels
- Different mosque engagement patterns
- Both frequent and occasional users
- Include both genders (separate sessions if needed)
```

**Session Setup:**
```
- Duration: 90-120 minutes
- Participants: 6-8 people per session
- Location: Comfortable, neutral space
- Recording equipment (with permission)
- Refreshments and comfortable seating
```

### Session Structure

**Phase 1: Introduction (15 minutes)**
```
1. Welcome and introductions
2. Explanation of Smart Mosque concept
3. Ground rules for discussion
4. Consent for recording
5. Icebreaker question about mosque experiences
```

**Phase 2: Current Experience Exploration (25 minutes)**
```
Discussion Topics:
- Typical mosque visit journey
- Current pain points and frustrations
- Information access challenges
- Communication gaps
- Facility comfort issues
- Community connection aspects
```

**Phase 3: Smart Mosque Vision (30 minutes)**
```
Discussion Topics:
- Reaction to Smart Mosque features
- Perceived benefits and concerns
- Feature prioritization and trade-offs
- Technology acceptance factors
- Privacy and security concerns
```

**Phase 4: Feature Deep Dive (30 minutes)**
```
Discussion Topics:
- Mobile app features and design
- Notification preferences
- Digital payment comfort
- Live streaming value
- Community engagement features
- Feedback and support mechanisms
```

**Phase 5: Implementation Concerns (15 minutes)**
```
Discussion Topics:
- Adoption barriers and enablers
- Training and support needs
- Change management concerns
- Success factors and metrics
```

**Phase 6: Wrap-up (5 minutes)**
```
- Summary of key insights
- Next steps communication
- Thank you and contact information
```
